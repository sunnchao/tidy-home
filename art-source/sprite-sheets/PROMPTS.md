# Tidy Home realistic sprite prompts

All accepted sheets were generated with the built-in OpenAI GPT Image tool and `transparent_background: true`. The tool does not expose its exact model revision. Each source PNG has a genuine alpha channel. The sheet numbers and object order match `scripts/extract-sprite-sheets.py`.

## Shared prompt prefix

> Use case: product-mockup. Asset: original game sprite atlas for Tidy Home. Create a square 3×3 grid of nine separate original realistic 3D product renders. Each centered in its own equal square cell, centers exactly at 1/6, 1/2, 5/6 in each axis. Keep 12% minimum empty margin on all sides of every individual cell, use the available size generously, with nothing crossing a cell border or touching. No grid lines. True-to-life shapes, proportions and materials, physically based shading, soft studio key light from upper left, subtle ambient occlusion, natural and slightly vivid colors. Consistent elevated three-quarter camera, looking down approximately 35 degrees. Clean, easy-to-read silhouettes at 90 px. No outlines, ink lines, cel shading, cartoon styling, text, numbers, logos, floor or background cast shadows. Genuine transparent background with alpha cutouts, including gaps such as handles. Precise masks, no glow outside silhouettes. Exact row-major order.

The shared prefix and each sheet's suffix form its final prompt. Sheets 01, 02, 03, 04, 05, and 12 specify their prefix variations below.
